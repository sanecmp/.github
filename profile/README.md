# sanecmp

Local-first digital wellbeing for families: schedules, session limits and
application rules, managed in a browser. Settings and usage statistics stay on
your own devices; no cloud account is required.

- [sanea](https://github.com/sanecmp/sanea) — the parent-facing web application.
- [sanex](https://github.com/sanecmp/sanex) — an autonomous service for Debian-based
  Linux with GNOME, on the child's computer.
- [sanelib](https://github.com/sanecmp/sanelib) — the shared network protocol.
- [saneinteg](https://github.com/sanecmp/saneinteg) — integration checks and local
  development tools.

Monitoring and limits are off by default and enabled per local user account.
Device communication uses mutual TLS.
